# DSH Harmony 设计系统

日期：2026-11-01

状态：权威视觉与动效基线。与本文冲突的局部常量应在触达时迁移到
`NativeDesign.ets` 与 `NativeMotion.ets`。

## 产品气质

**Quiet Precision / 克制精确**：紧凑、安静、信息优先，像一个可靠的开发工具，
而不是营销页或通用表单。界面依靠排版、对齐、细描边和真实业务图标建立层次。
动效用于解释来源、去向和状态变化；触控反馈要快，结构动画要有明确收束。

三个关键词：

- **Compact**：相近信息放在同一行或同一组，不用大标题和大留白制造层级。
- **Explicit**：等待、运行、失败、选中、可展开和只读均有非动画替代表达。
- **Continuous**：返回、折叠、抽屉和预览的进入/退出路径成对，系统返回与可视
  返回按钮走同一状态路径。

颜色规则：

- 正文绝不使用纯黑；浅色主文本为近黑，深色主文本为近白。
- DeepSeek 蓝只用于少量需要行动或定位的元素，不能铺满页面。
- 新增/删除统计同时使用符号和颜色，不能只依赖红绿。
- SVG 进入 `DSHIcon` 后由语义色调解析器重新着色；资源文件不烘焙主题色。
- 减少透明度、后台和低电量时不得依赖透明材质表达层级。

## 排版

| 角色 | 字号 | 样式 |
| --- | ---: | --- |
| Page title | 20fp | Medium/Bold，单行或两行 |
| Header title | 18fp | Medium |
| Body / row title | 14fp | Regular/Medium |
| Compact row | 13fp | Regular |
| Caption | 11fp | Regular |
| Micro / count | 10fp | Regular/Medium |
| Code | 12fp | Monospace，固定行高 |

标题字号随系统字体缩放。正文使用明确最大行数和省略，不靠极细灰色小字承载关键
操作。界面内置说明使用短句；实现原理和部署细节放到设置中的独立说明页或仓库文档。

## 空间、形状与密度

基础间距为 4、8、12、16vp。全页水平 inset 为 16vp；手机抽屉可由 12vp 开始，
但内部内容保持同一对齐线。卡片组使用 16vp 外圆角，行使用 12vp 反馈圆角，
控件使用 10vp，紧凑状态使用 8vp，Sheet/Surface 可使用 24vp。

| 配方 | 高度 | 说明 |
| --- | ---: | --- |
| Compact disclosure | 44vp hit | 可见内容可维持 30–32vp 的密度，但点击区域覆盖整行 |
| Standard row | 48vp | 文件、设置、工作区选择 |
| Picker row | 46vp | 模型与推理项 |
| Header | 52vp | 页面标题与操作 |
| Icon control | 44vp hit / 36vp visual | 三点、返回、关闭、搜索、下载 |
| Primary action | 44–48vp | 连接、发送、确认 |

行内图标视觉大小通常为 14–18vp。图标按钮的视觉底和交互热区必须分离，不能为了
紧凑把可点击区域缩到 28–32vp。

## 表面与组件配方

### 页面 Header

- 左返回、标题、右侧一个最多两个图标操作。
- 只在打开某页时出现，不作为所有页面的永久 App 顶栏。
- 关闭、返回和系统 Back 共享导航栈；不得一个页面用 X、另一页面用 `<` 表示相同动作。

### 列表组

- 组使用 Raised 背景、16vp 圆角、组内 Divider。
- 行标题 14fp，说明 11fp；右侧 detail 最多一行。
- 点击反馈覆盖整行，不能只高亮图标。
- 二级菜单统一从右侧进入、向右侧退出。

### 抽屉

- 从左侧进入，最大宽度按手机比例限制。
- 蒙版和抽屉共用一个进度时钟；遮罩播放透明度变化，同时提供柔和侧向阴影。
- 内容安全区影响内容对齐，不影响顶部安全区背景。
- 当前会话选中态在手机和宽屏一致。

### 浮层

- 菜单、模型气泡和检查器使用 Overlay 表面、16vp 圆角、锚定位置。
- 不默认添加全屏遮罩；点击外部由浮层自己的透明 hit layer 关闭。
- 打开后先显示缓存，再局部刷新；不能出现空白 loading 帧。

### 消息与过程

- 用户消息靠右、限制宽度；助手正文铺开。
- 推理、工具、文件读取和执行命令使用一行摘要，展开后正文进入限高滚动容器。
- 最新运行步骤默认展开；历史步骤保留用户选择。
- 流式 token 和增量历史不播放逐项入场动画。

### 文件与媒体

- 浏览器先文件夹后文件，分组标题统一。
- 预览头包含标题、加载标记、复制路径、下载和关闭。
- 预览模式/代码模式使用 44vp 热区，视觉开关可更小。
- 灯箱关闭和下载位于顶部安全区内；背景点击退出，双击放大，放大后可拖动。

## 状态语言

| 状态 | 表达 |
| --- | --- |
| Loading | 12–16vp 小 spinner 位于标题行或内容中心；不把 Dock 推向下方 |
| Empty | 单行说明和可执行下一步；不使用大插图占满页面 |
| Error | 短错误文本 + 重试；同时在可操作表面保留原输入 |
| Waiting | 黄色圆点/字标 + “等待确认” |
| Running | 蓝点或 spinner + 实时步骤摘要 |
| Success | 完成语义文本；需要统计时附 +N/-N |
| Disabled | 降低对比并保留合理轮廓，不能仅靠透明度导致不可读 |

Toast 只用于短暂操作结果。保存成功的偏好不显示 Toast，仅在错误时反馈；复制可按
既有交互使用图标状态，但不得推动页面布局。

## 动效

### 语义时长

| Token | 时长 | 用途 |
| --- | ---: | --- |
| `press` | 90ms | 按下、松开 |
| `micro` | 140ms | 选中、箭头、开关、短状态 |
| `overlay` | 190ms | 菜单、气泡 |
| `navigation` | 220ms | 设置和文件二级页 |
| `mask` | 240ms | 抽屉遮罩透明度 |
| `surface` | 260ms | 大表面、预览 |
| `drawer` | 280ms | 抽屉位移与收束 |
| `scrollReturn` | 280ms | 非线性回到底部 |
| `brand` | 560ms | 首次引导的品牌旅程 |

退出通常比进入短 40–60ms。弹簧用于直接操作和有限的空间落位，不能给高频文本更新
或整表重排使用弹簧。

### 方向

- 进入二级页：从右轻移 10vp 并淡入；返回反向。
- 抽屉：从左侧进入并向左退出；蒙版先随抽屉出现，退出后消失。
- 展开：内容从锚点向下展开，箭头与正文同为一个状态更新。
- 文件预览：从内容表面轻微上移并淡入。
- 灯箱：淡入和不超过 4% 的 scale；关闭按进入方向。

### 禁止

- 流式 token 入场动画、整列表逐项弹入。
- 无状态的呼吸、漂浮、持续旋转和装饰粒子。
- 动画完成前写业务状态；动画不得成为操作成功的前置条件。
- 抽屉遮罩与抽屉使用两个不相关时钟。

## 无障碍与系统能力

- 所有图标按钮提供可读标签；选中、展开、禁用和无新内容有文本/状态表达。
- 触控目标至少 44×44vp；文字缩放不能挤压图标热区。
- 减少动效时页面、抽屉、菜单和滚动返回直接到终态。
- 减少透明度时所有材质退回实色；API 23 不使用 API 26 材质。
- 状态栏内容进入安全区；底部输入与手势区之间使用 1.2× 导航条高度的轻量偏移。
- 文件预览安全区必须包住顶部操作和底部横向滚动条。

## 例外

1. 兼容模式中的 DSH Web 页面保持上游视觉，只向侧栏注入原生设置入口。
2. 桌面卡片运行在系统桌面宿主中，使用独立深浅资源，但文字层级和 DSH 语义色应与
   应用保持一致。
3. PDFKit 的暗色画布能力受系统实现限制；容器可主题化，文档页面本身不得强制
   反色。该限制记录在独立研究文档中。
4. 图片灯箱使用黑色媒体背景，这是全屏媒体预览的语义例外，操作图标仍保持 44vp。
