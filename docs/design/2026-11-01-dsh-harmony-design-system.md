# DSH Harmony 设计系统

日期：2026-11-01

状态：权威视觉与动效基线。与本文冲突的局部常量应在触达时迁移到
`NativeDesign.ets` 与 `NativeMotion.ets`。

## 产品气质

**Quiet Precision / 克制精确**：紧凑、安静、信息优先，像一个可靠的开发工具，
而不是营销页或通用表单。界面依靠排版、对齐、细描边和真实业务图标建立层次。
动效用于解释来源、去向和状态变化；触控反馈要快，结构动画要有明确收束。

三个关键词：

- **Compact**：相近信息放在同一行或同一组，不用大标题和大留白制造层级。
- **Explicit**：等待、运行、失败、选中、可展开和只读均有非动画替代表达。
- **Continuous**：返回、折叠、抽屉和预览的进入/退出路径成对，系统返回与可视
  返回按钮走同一状态路径。

颜色规则：

- 正文绝不使用纯黑；浅色主文本为近黑，深色主文本为近白。
- DeepSeek 蓝只用于少量需要行动或定位的元素，不能铺满页面。
- 新增/删除统计同时使用符号和颜色，不能只依赖红绿。
- SVG 进入 `DSHIcon` 后由语义色调解析器重新着色；资源文件不烘焙主题色。
- 减少透明度、后台和低电量时不得依赖透明材质表达层级。

| --- | ---: | --- |

| Header title | 18fp | Medium |
| Compact title | 15fp | Medium，浮层或双行卡片主标题 |
| Body / row title | 14fp | Regular/Medium |
| Compact row | 13fp | Regular |
| Section | 12fp | Medium/Regular，组标题或次级正文 |
| Caption | 11fp | Regular |
| Micro / count | 10fp | Regular/Medium |

| Metric | 28fp | Medium，仅存储等单值指标 |

标题字号随系统字体缩放。正文使用明确最大行数和省略，不靠极细灰色小字承载关键

组件不得再新增 9/16/17/21fp 等局部字号；需要新层级时先扩展本表与
`NativeDesign.ets`。

## 空间、形状与密度

基础间距只使用 2、4、8、12、16、20、28vp。全页水平 inset 固定为 16vp；手机
抽屉可用 12vp，但标题、分组、行和状态必须共用抽屉内部的一条内容边线。相邻轻量
控件默认间距为 8vp，表单分组间距为 12vp。

### 形状

| 角色 | 圆角 | 用途 |
| --- | ---: | --- |
| Badge | 6vp | 一至两字状态、版本号 |
| Compact | 8vp | 紧凑内嵌按钮、文件块内行 |
| Control | 10vp | 输入框、按钮、图标底 |
| Row | 12vp | 点击反馈、预览行、菜单行 |
| Chip | 14vp | 28vp 高的 pill/chip |
| Group | 16vp | 列表组、卡片、浮层 |
| Surface | 24vp | 登录/失败等完整 Sheet |

圆形控件使用显式宽度的一半作为圆角。不得再出现 5/7/9/11/13/15/18vp 等
近似但无语义的小圆角。

### 控件高度

| 角色 | 高度 | 用途 |
| --- | ---: | --- |
| Chip | 28vp | 状态、筛选、计划标签 |
| Dense control | 32vp | 图标操作、紧凑文字按钮 |
| Compact inline | 36vp | 输入行、双行紧凑按钮、工具动作 |
| Compact row | 44vp | 设置单行选项、抽屉、选择项、单行字段、紧凑列表 |
| Standard row | 48vp | 文件、主导航和主操作 |
| Header | 52vp | 页面标题与最多两个操作 |
| Double-line row | 60vp | 插件、自动化等固定双行内容 |
| Icon control | 44vp hit / 36vp visual | 返回、关闭、搜索、下载、更多 |

44vp 触控热区不能被视觉容器替代。32/36vp 只用于控件自身，图标按钮仍须有
44vp 热区；如果父行本身可点击，整行必须由 44/48/60vp 的语义高度承载。

`设置 > DSH 设置` 中包含 44vp `Select` 的选项行使用 60vp 行节奏，并在控件
上下各保留 8vp 内边距。分隔线位于行边界，不得贴住 Select；单行导航行仍保持
44vp，不得为增加间距而放大整页。

### 对齐规则

- 同一页面的标题、首行、卡片内容边线、loading/empty/error 状态和底部操作共用
  16vp 页面 inset；只有抽屉、灯箱和贴边媒体可声明例外。
- 行内容左右 inset 固定为 12vp；图标操作占用 44vp 时，其视觉图形中心必须与
  相邻文字行的图标列对齐。
- 同一行内图标只使用 10/12/14/16/18/20vp 的角色。chevron 不得因页面不同
  出现 11/12/13/15/16vp 混用。
- Loading 行内使用 14vp spinner，页面或大容器中心使用 24vp spinner；同一场景
  的重试按钮沿用相邻主控件的 48vp 或 36vp 角色。
- 会话标题下方的任务计划浮动横幅头部使用 32vp Dense control；展开后的任务内容
  独立滚动，不抬高头部、不挤压正文。
- 文件名优先于目录；目录只作为第二行辅助信息。任何路径都不得挤占固定 `+/-`
  指标、尾部操作或点击热区。
- 启动页品牌图标可与背景层叠，但登录、恢复和错误 Sheet 必须从图标完整边界下方
  开始，至少保留 28vp 净空；不得出现品牌图标被 Sheet 切断或在标题后方只露出
  半截的构图。
- 媒体缩略图、头像、状态点、品牌插画和进度条可保留内容尺寸，但它们的容器、
  caption 和操作热区仍使用上述语义角色。

## 表面与组件配方

### 页面 Header

- 左返回、标题、右侧一个最多两个图标操作。
- 只在打开某页时出现，不作为所有页面的永久 App 顶栏。
- 关闭、返回和系统 Back 共享导航栈；不得一个页面用 X、另一页面用 `<` 表示相同动作。

### 列表组

- 组使用 Raised 背景、16vp 圆角、组内 Divider。
- 行标题 14fp，说明 11fp；右侧 detail 最多一行。
- 点击反馈覆盖整行，不能只高亮图标。
- 二级菜单统一从右侧进入、向右侧退出。

### 抽屉

- 从左侧进入，最大宽度按手机比例限制。
- 蒙版和抽屉共用一个进度时钟；遮罩播放透明度变化，同时提供柔和侧向阴影。
- 内容安全区影响内容对齐，不影响顶部安全区背景。
- 当前会话选中态在手机和宽屏一致。

### 浮层

- 菜单、模型气泡和检查器使用 Overlay 表面、16vp 圆角、锚定位置。
- 不默认添加全屏遮罩；点击外部由浮层自己的透明 hit layer 关闭。
- 打开后先显示缓存，再局部刷新；不能出现空白 loading 帧。

### 启动与首次运行

- 快速迭代提示是启动阶段，不是工作区上的阻塞弹层。首次确认前显示；确认后
  沿用原有欢迎、恢复和登录分支；退出登录后重新显示。
- 提示页与欢迎页必须复用同一个 logo 尺寸、坐标和内容锚点。确认时 logo 不得
  位移、缩放或重建，只允许下方内容使用 `brand` 语义动效淡入和轻微收束。
- 提示页使用一个 28vp 及以下状态的紧凑 chip、一个页面标题、两段短说明和一个
  48vp 确认按钮；不再增加第二个主操作或装饰插画。
- 文案要说明项目处于快速迭代期、仍有未完成功能和 Bug，并引导用户从项目仓库
  提交 Issue；不承诺时间表，不把产品说明写成营销页。
- 系统 Back 在提示页被消费，用户必须明确确认。减少动态效果时必须直接落到
  欢迎页最终几何。
- 提示页遵守统一 16vp 内容 inset、亮暗主题语义色和 20vp 底部安全基线。

### 消息与过程

- 用户消息靠右、限制宽度；助手正文铺开。
- 推理、工具、文件读取和执行命令使用一行摘要，展开后正文进入限高滚动容器。
- 最新运行步骤默认展开；历史步骤保留用户选择。
- 流式 token 和增量历史不播放逐项入场动画。
- 已发送用户消息中的高置信度凭据默认只遮挡显示；复制、重试、编辑和模型
  输入始终使用原文。有凭据时显示一个 44vp 紧凑“显示凭据/隐藏凭据”动作，
  不把原文写入状态、日志或测试快照。
- 遮蔽值使用等宽内联 run，且先于 Markdown 强调解析；长消息虚拟化窗口不得
  切断任一凭据 span，避免分片后漏识别或星号被二次解析。
- 流式 Markdown 只修复未完成的最后一块。未闭合强调、删除线、行内代码、
  链接、图片、标签、表格分隔行和代码围栏不得在闭合前闪出错误版式；闭合到达
  后必须收敛到与完成态一致的阅读位置。

### 文件与媒体

- 浏览器先文件夹后文件，分组标题统一。
- 预览头包含标题、加载标记、可选模式切换、下载和关闭；任何文件预览都不显示
  复制路径或复制文件动作。
- 渲染/源码使用标题栏内的单个图标动作，44vp 热区、36vp 视觉容器；
  不再占用独立第二行。图标表达可切换到的目标模式。
- 配置、日志、dotfile、无扩展名开发文件和未知非二进制文本直接进入阅读器，
  不先显示“未知类型”；已知二进制只在元数据可用时显示下载入口和单行说明，
  不把替换字符当作文件正文。
- CSV/TSV 使用同一阅读器内的只读表格投影：行号、A/B/C 列标、168vp 单元格、
  横向与纵向滚动，首行仍是数据而不是语义表头。表格文本按字面显示，不解析
  Markdown；超限只截断表格投影并保留完整源码，不截断原文件。
- 分隔文本的表格/源码仍使用标题栏单个目标模式图标，不增加第二工具栏。
- 灯箱关闭和下载位于顶部安全区内；背景点击退出，双击放大，放大后可拖动。

### 设置搜索

- 设置根页标题下使用 44vp 单行搜索框，沿用 Field 表面和页面 16vp 内容边线。
- 搜索同时覆盖中文、英文、旧名称、同义词与页面路径；先匹配标题，再匹配
  同义词和路径，同分结果保持索引声明顺序。
- 搜索框只替换设置列表主体，不改变标题、安全区或整体页面框架。清除后立即
  恢复原分组，不播放整表入场动画。
- 结果行沿用 44vp 紧凑行。标题优先，页面路径作为次级信息单行省略；结果只
  导航到所属页面，不允许直接修改设置值。

## 状态语言

| 状态 | 表达 |
| --- | --- |
| Loading | 行内 14vp 或页面中心 24vp spinner；不把 Dock 推向下方 |
| Empty | 单行说明和可执行下一步；不使用大插图占满页面 |
| Error | 短错误文本 + 重试；同时在可操作表面保留原输入 |
| Waiting | 黄色圆点/字标 + “等待确认” |
| Running | 蓝点或 spinner + 实时步骤摘要 |
| Success | 完成语义文本；需要统计时附 +N/-N |
| Disabled | 降低对比并保留合理轮廓，不能仅靠透明度导致不可读 |

Toast 只用于短暂操作结果。保存成功的偏好不显示 Toast，仅在错误时反馈；复制可按
既有交互使用图标状态，但不得推动页面布局。

## 动效

### 语义时长

| Token | 时长 | 用途 |
| --- | ---: | --- |
| `press` | 90ms | 按下、松开 |
| `micro` | 140ms | 选中、箭头、开关、短状态 |
| `overlay` | 190ms | 菜单、气泡 |
| `navigation` | 220ms | 设置和文件二级页 |
| `mask` | 240ms | 抽屉遮罩透明度 |
| `surface` | 260ms | 大表面、预览 |
| `drawer` | 280ms | 抽屉位移与收束 |
| `scrollReturn` | 280ms | 非线性回到底部 |
| `brand` | 560ms | 首次引导的品牌旅程 |

退出通常比进入短 40–60ms。弹簧用于直接操作和有限的空间落位，不能给高频文本更新
或整表重排使用弹簧。

### 方向

- 进入二级页：从右轻移 10vp 并淡入；返回反向。
- 抽屉：从左侧进入并向左退出；蒙版先随抽屉出现，退出后消失。
- 展开：内容从锚点向下展开，箭头与正文同为一个状态更新。
- 文件预览：从内容表面轻微上移并淡入。
- 灯箱：淡入和不超过 4% 的 scale；关闭按进入方向。

### 禁止

- 流式 token 入场动画、整列表逐项弹入。
- 无状态的呼吸、漂浮、持续旋转和装饰粒子。
- 动画完成前写业务状态；动画不得成为操作成功的前置条件。
- 抽屉遮罩与抽屉使用两个不相关时钟。

## 无障碍与系统能力

- 所有图标按钮提供可读标签；选中、展开、禁用和无新内容有文本/状态表达。
- 触控目标至少 44×44vp；文字缩放不能挤压图标热区。
- 减少动效时页面、抽屉、菜单和滚动返回直接到终态。
- 减少透明度时所有材质退回实色；API 23 不使用 API 26 材质。
- 状态栏内容进入安全区；底部输入与手势区之间使用 1.2× 导航条高度的轻量偏移。
- 所有原生页面、抽屉、浮层、预览和底部操作的
  `nativeSafeBottom` 必须至少为 20vp；系统上报更小的手势区时也不得低于该值。
  Dock 等需要额外呼吸空间的表面可在 20vp 下限之上继续增加 offset。
  输入法出现时，Composer 与输入法之间使用 12vp，而不是继续叠加 20vp 页面
  安全区。
- 文件预览安全区必须包住顶部操作和底部横向滚动条。

### 会话标题操作

- 子智能体入口在标题栏只显示 `branch-outline` 与当前直接子智能体数量，例如
  `branch-outline 4`；不显示“个子智能体”长文案或额外下拉箭头。
- 子智能体入口使用 44vp 透明触控区承载 28vp 内层胶囊。按压高亮、边框和裁切
  只作用于内层胶囊，外圈不得出现矩形 ripple 或矩形背景。
- 运行状态通过图标和数字的 accent 色表达，不再增加状态点；完整语义
  “4 个子智能体，正在运行”保留在 accessibility text 中。
- 入口视觉高度 28vp、使用紧凑 chip 表面；标题列优先获得剩余宽度，长标题先
  省略，入口和 44vp“更多”热区不得被压缩。

### 问题卡

- 问题头只在顶部显示类别，例如“界面偏好”；题号 `1 / N` 只在底部左下方出现一次。
- 类别文字相对卡片顶部保留紧凑 inset，题目标题紧接说明区，不重复制造大段
  垂直空白。
- 自定义回答输入框中的 placeholder 必须与输入框视觉垂直居中。
- “跳过”和底部主提交动作使用 32vp 高紧凑按钮与 11fp 字号；它们不能沿用
  44vp 普通操作高度。

## 例外

1. 兼容模式中的 DSH Web 页面保持上游视觉，只向侧栏注入原生设置入口。
2. 桌面卡片运行在系统桌面宿主中，使用独立深浅资源，但文字层级和 DSH 语义色应与
   应用保持一致。
3. PDFKit 的暗色画布能力受系统实现限制；容器可主题化，文档页面本身不得强制
   反色。该限制记录在独立研究文档中。
4. 图片灯箱使用黑色媒体背景，这是全屏媒体预览的语义例外，操作图标仍保持 44vp。
5. 兼容模式中的上游 Web 控件保留其原始 CSS 尺寸；只有原生注入的设置入口遵循
   本设计系统。
