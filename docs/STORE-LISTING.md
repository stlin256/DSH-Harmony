# AppGallery 商店文案

应用名称：**DSH Mobile**

## 一句话简介（副标题，≤ 80 字）

在手机上接入你自己的 DeepSeek Harness 工作空间：继续对话、查看任务过程、浏览文件。

## 详细介绍

**DSH Mobile 是一款让你在手机上接入自建 DeepSeek Harness 工作空间的客户端。**

DSH Mobile 把桌面端的开发工作带到手机上：随时查看工作区里的会话，接着往下聊，看一眼任务执行到哪一步，翻一翻项目文件。无论你是在通勤路上还是离开工位，都能继续手上的工作。

### 核心功能

**工作区与会话**
DSH Mobile 按工作区分组展示所有会话，支持搜索、置顶和按最近交互排序，会话多了也能快速找到。

**原生对话体验**
DSH Mobile 延续 DSH 紧凑清晰的信息层级。Markdown、代码高亮、表格、差异对比和图片都能正确呈现，长回答读起来不累。

**任务过程可见**
DSH Mobile 按执行顺序展示思考、文件读取、命令执行和结果，可以逐层折叠展开，随时知道它做了什么。

**文件浏览**
DSH Mobile 支持浏览工作区目录，预览 Markdown、代码、SVG、PNG 等常见格式，需要时保存到本地。文件操作默认只读，不会误改你的项目。

**个性化设置**
DSH Mobile 提供亮色、暗色或跟随系统外观，可单独关闭动态效果与透明效果，适应不同使用习惯。

**通知与桌面卡片**
DSH Mobile 为完成、失败、待审批等不同状态分别设置通知级别，通过通知或桌面卡片查看任务状态，点一下直接跳到对应会话。

**多种连接方式**
DSH Mobile 支持 DSH 原生登录流程，也可按你的部署环境接入受支持的 Passkey 认证。

### 使用前提

使用 DSH Mobile 需要你**自行部署或已获授权使用** DeepSeek Harness 服务。

- DSH Mobile 本身不提供任何 AI 模型、算力或账号，也不代理推理请求。
- DSH Mobile 不会绕过服务器端认证，身份校验与权限判定完全由你自己的服务端决定。
- 未连接自建服务时，DSH Mobile 无法进行对话或调用任何模型。
